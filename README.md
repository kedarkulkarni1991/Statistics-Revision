# Introduction to Statistics — Revision Notes

A short revision document covering the basic statistics concepts taught in
*Introduction to Statistics and Computing* at Azim Premji University.

**[Download the PDF](statistics-revision.pdf)** — 28 pages.

Each section states the idea, gives the formula, and works through one or two
examples. There are no practice sets or question banks: this is meant for
revising material already taught, not for learning it from scratch.

## Contents

| Part | Sections |
|:--|:--|
| **I. Describing data** | Central tendency · Dispersion · Scatter plots and correlation |
| **II. Probability** | Sample space and events · Axioms · Conditional probability and independence · Bayes' theorem |
| **III. Discrete random variables** | Random variables and the pmf · Expectation and variance · Binomial · Poisson · Negative binomial |
| **IV. Continuous random variables** | From mass to density · Uniform · Normal and the empirical rule · Standard normal and z-scores |

Sixteen sections, twenty-one worked examples, thirteen figures. R code
accompanies each topic, and every snippet has been run.

## Building it

```bash
Rscript make-figures.R                     # regenerate the figures
pdflatex statistics-revision.tex           # twice, for the table of contents
pdflatex statistics-revision.tex
```

Requires R with **ggplot2**, and a LaTeX installation with `tcolorbox`,
`listings`, `enumitem`, `titlesec`, `booktabs`, `mathpazo` and `placeins`.

### On Overleaf

Upload the **whole folder**, or a zip of it. The document references figures as
`figures/*.png`, so uploading `statistics-revision.tex` on its own will not
compile.

## Figures

All thirteen figures are generated by [`make-figures.R`](make-figures.R) rather
than being pasted in as images, so any of them can be reproduced or modified.
Three do more than decorate:

- **Central tendency** plots mode, median and mean on a right-skewed income
  distribution, in that order — the reason the median is the usual summary for
  income.
- **The empirical rule** shows 68/95/99.7 as nested bands, with the labels on
  brackets below the axis rather than on the curve.
- **Standardising** shows the same normal distribution before and after the
  $z$ transformation, so that $x = 700$ and $z = 1.91$ are visibly the same
  point in different units.
